# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-01-29

### Added
- **NEW**: Verbatim explorer with keyword highlighting in Exploration page
  - Filter verbatims by theme
  - Highlight matched keywords in bold
  - View up to 50 verbatims per theme
  - Display metadata (date, duplicate flag)
- **NEW**: `src/utils/encoding.py` - Unicode encoding utilities
  - `fix_double_encoding()` for Latin-1/UTF-8 double encoding issues
  - `fix_encoding_in_list()` and `fix_encoding_in_dict()` helpers
- **NEW**: `docs/METRIQUES_QUANTIFICATION.md` - Complete quantification metrics documentation
  - Volume (verbatims) vs Volume (mentions) explanation
  - Real-world examples and interpretation guide
  - FAQ and troubleshooting
- Real data integration in Cleaning page
  - Preview shows actual project verbatims (not fake data)
  - Duplicate detection on real dataset samples
  - Actual cleaning and deduplication execution
- Real data integration in Quantification page
  - Displays actual analysis results from database
  - Shows real ontologies generated by LLM
  - Real volumes and percentages

### Changed
- **BREAKING**: Replaced emoji sentiment display with percentage proportions
  - Before: "😢 Pain", "😊 Bénéfice", "😢😊 Mixte"
  - After: "60% Pain / 40% Bénéfice", "100% Pain / 0% Bénéfice"
  - More informative for understanding theme sentiment distribution
- Quantification page now shows real analysis results instead of simulations
- Cleaning page uses real verbatims for preview and duplicate detection
- All pages convert ORM objects to dictionaries to avoid DetachedInstanceError

### Fixed
- **Critical**: Fixed DetachedInstanceError across multiple pages
  - Exploration page: Convert RunTopic to dict before session closes
  - Exploration page: Convert ProjectVerbatim to dict for verbatim explorer
  - Quantification page: Convert RunTopic and ProjectOntology to dicts
  - Root cause: Accessing ORM lazy-loaded attributes outside session context
- **Critical**: Fixed DuplicatePreparedStatement error when saving analysis
  - Removed `db.flush()` inside loop (conflicted with psycopg3 prepared statements)
  - Generate UUID explicitly with `uuid.uuid4()` before creating objects
  - Single `db.commit()` at end instead of multiple flushes
- **Critical**: Fixed null topic_id constraint violation
  - Explicitly assign UUID to both RunTopic and ProjectOntology
  - Ensures foreign key relationship without requiring flush
- **Critical**: Fixed quantification metrics showing 0 for all topics
  - Corrected data structure extraction: `item['metrics']['volume_verbatims']`
  - Pipeline returns nested structure: `{topic: {...}, ontology: {...}, metrics: {...}}`
- **Critical**: Fixed double UTF-8 encoding in keywords display
  - "efficacité" displayed as "efficacitÃ©" → Now displays correctly
  - "résultats" displayed as "rÃ©sultats" → Now displays correctly
  - Added `fix_double_encoding()` to convert Latin-1 bytes back to UTF-8
- Fixed column name errors throughout codebase
  - `is_duplicate` → `dedup_flag` (correct schema name)
  - `cleaned_text` → `full_text_clean` (correct schema name)
  - Prevents AttributeError on ProjectVerbatim model
- Fixed Unicode escape sequences display (\u00e9)
  - Keywords now decode properly: "efficacité" instead of "efficacit\u00e9"
  - Applied to all keyword and regex pattern displays

## [1.0.0] - 2026-01-16

### Added
- Initial MVP implementation complete
- 7 EPICs implemented according to specifications v1.2
- Supabase backend support (dual PostgreSQL/Supabase)
- LangGraph orchestration pipeline
- Streamlit UI with 5 pages (Import, Cleaning, Analysis, Quantification, Exploration)
- GIDA ontology integration (version 2026.01, 22 entities)
- Complete database schema (11 tables)
- 2-pass topic merging (algorithmic + LLM)
- Fuzzy deduplication with RapidFuzz
- Stratified sampling for rapid analysis mode
- Python deterministic quantification with negation handling
- Export functionality (Excel, CSV, Markdown)

### Features
- Import CSV from Brandwatch/Semantiweb/Generic sources
- Configurable text cleaning options
- Fuzzy deduplication (threshold 0.80-0.95)
- LLM-powered thematic analysis (GPT-4 Turbo)
- Rapid mode (750 verbatims) and Full mode (unlimited with chunking)
- Topic merging with fuzzy matching and Jaccard similarity
- Ontology generation (keywords, regex, negations)
- Entity recognition for GIDA reference data
- Interactive exploration with filters
- Multi-format export capabilities
